# גיבויי לוח התיקונים

כל תיקייה כאן היא גיבוי מלא של לוח התיקונים של השף הירוק, לפי תאריך.

- board-backup.json - כל הנתונים: פריטים (כולל ארכיון), בקשות ותשובות, לוג שינויים.
- items.csv - טבלת הפריטים, נפתחת באקסל.
- board-backup.md - אותו תוכן כמסמך קריא.
- board-page.html - העמוד עצמו עם הנתונים המוטמעים בו, לשחזור מלא.
